# Clackblade specimen-derived title font

Source: the alphabet screenshot supplied by the user in this task, retained as specimen.png. The specimen identifies the design as Blackbit by Angin Studio: https://anginstudio.com/product/blackbit-retro-game-pixelated-fonts . This reconstruction is not the original Blackbit OTF. No original font binary or license file was supplied; do not label the generated binary as an official Angin release or claim ownership of the source design.

Run `python design/clackblade-branding/build-font.py --keep-wordmark` from the repository root (existing Pillow and fontTools). `specimen-v2.png` is the user's full-resolution1200x800 reference; `specimen.png` preserves the earlier768x512 input. Bright green source pixels are isolated using G>=170, G>=R+25 and G>=B+70. Explicit glyph bounds and source baselines preserve detached dots and descenders. Shared pixel edges are cancelled before tracing closed glyph boundaries; the earlier separate contour per raster row produced seams at small sizes. No glyph shapes are invented.

The TTF has78visible glyphs (62letters/digits and16pictured punctuation symbols) plus space,1600units/em and16units per reference pixel. All78glyphs rasterize pixel-identically against their source masks at native100px/em; repeated generation is byte-identical. `--keep-wordmark` preserves the existing marketing wordmark. Existing published banner/cover/gallery exports are untouched.

`BlackletterTitleBuild` retains the original `ClackbladeSpecimenPixel64.asset` GUID for the title and uses `ClackbladeSpecimenUI100.asset` (100px/em SDF,8px gutter) for small UI text. The final pass covers both scenes, hidden UI, input-field font configuration and all text prefabs/runtime clones. The three TypingManager word references retain their original font/material and character coloring. VT323 supplies only symbols/accents outside the pictured subset. Bounds, colors and wrapping remain; UI text fits up to its authored maximum size. The corrected Unity assets and runtime appearance are being verified in the page checkpoint.
