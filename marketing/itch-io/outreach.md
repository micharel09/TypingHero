## 14-day experiment

No paid advertising. Before posting, choose one typing community and one indie
community with an explicit self-promotion area; check each location's current
rules and adapt the prepared message to the allowed format. No community/channel
has been selected or contacted. User instruction for the exact destinations and
messages is required before posting.

The 14-day outreach experiment begins when the first approved post is actually
published. Until then, the page update is a separate change. Record the timestamp,
community, post URL, final message and clip for each post here. Record fresh
analytics immediately before that first post, then at +7 and +14 days. Use the
same reporting window when comparing referrers.

Use changes in counters, not absolute totals, when comparing periods. Views and
Browser Plays are events, not unique people. Owner QA runs can affect counters;
note them rather than claiming every increment is a newly acquired player.
External referrers do not cover all traffic. A play/view ratio does not measure
in-game retention or establish why someone left.

If views remain low, review distribution channels. If views rise without a
corresponding rise in plays, inspect the page promise, desktop/keyboard requirement
and Run game flow. Track voluntary comments, ratings and collections separately.

they do not guarantee reach or a particular conversion rate.
