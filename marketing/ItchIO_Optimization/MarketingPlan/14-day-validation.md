# 14-day acquisition experiment - zero ad budget

Day 0 means the first outbound post, not the date these assets were prepared. Allow 2-3 hours per week. After release, keep the approved CLACKBLADE cover and store copy fixed through this first test so acquisition changes are easier to interpret. This is a combined campaign observation, not a randomized A/B or isolated cover test.

Audience: English-speaking desktop action players who like timing and score improvement. Promise: **Type to slash. Press Space to parry.** Show real letters disappearing and the resulting sword hit in the first 2 seconds. CTA: free desktop browser play with a keyboard.

| Day | Work | Budget | Record |
| --- | --- | --- | --- |
| 0 | Take fresh matched-window baseline; publish type-to-attack Short using concept 1; use the real typing GIF as a supporting preview | 45-60 min | Time, exact destination/URL, footage build, clip impressions/views where offered |
| 3 | Play another suitable game and leave useful specific feedback; read current itch Get Feedback rules; post the prepared first-play question if permitted | 35-45 min | Post URL, referral changes and voluntary replies; no vote/review exchange |
| 6-7 | Publish parry Short, record the actual successful timing cue; capture second metrics | 40-50 min | Same windows, channel totals/deltas, QA log |
| 10 | Publish Slayer Short only with genuine current-build stamina break and rapid strikes | 30-45 min | Link, build and observed reaction; if no verified footage, postpone rather than use mislabeled older candidate footage |
| 14 | Compare weeks, summarize concrete first-play confusion; choose one next change | 25-35 min | Counts, denominators, uncertainty and next decision |

Use `SocialMedia/video-concepts.md` and ready captions. YouTube Shorts is the default, TikTok optional reuse. Export genuine gameplay to vertical MP4/H.264 with the full combat area and words visible, optional AAC audio, readable subtitles outside the HUD. See [YouTube upload formats](https://support.google.com/youtube/answer/12779649). Do not crop away the letters to fill a portrait frame; use background padding. Check the channel's actual clickable link route before saying link in bio/description. No channel upload was performed in this task.

[Get Feedback rules](https://itch.io/board/255031/get-feedback) were inspected on 2026-10-19: one topic per project, link required, specific feedback request, no frequent or low-effort promotional threads. Reuse an existing project thread if present. Draft: `SocialMedia/itch-feedback.md`. Reddit and creator copy are alternatives, not additional mandatory weekly commitments. Read current destination rules before posting; the attempted Reddit rule pages did not expose actual requirements. No outreach messages were sent.

Learning target: **50 additional visits from outside QA and 10 additional Browser Plays** in 14 days. This is a desired sample, not a growth promise. Report inability to isolate non-QA visits rather than claiming the target from raw totals. Browser Plays counts starts, not unique players. If only aggregate counts are available, report them with contamination limits.

## Decisions at day 14

| Observation | Next action |
| --- | --- |
| Still little exposure / external arrival | Change distribution hook or destination. Make the word-to-hit event the first frame; try one relevant permitted feedback space. Do not infer cover failure without exposures. |
| Measured impressions up, clicks weak on the same surface | Check that thumbnail text survives that surface's size; then test B while holding audience/caption stable. Report sample size and channel, not an itch-wide CTR claim. |
| Page visits up, Browser Plays weak in matching windows | Observe a fresh desktop visitor's page/load steps; check Run game visibility, keyboard expectation and actual load failures. Make a technical fix only when reproduced. |
| Plays up, people quit or get confused | Seek voluntary observation of the first duel; distinguish tutorial/controls confusion from load problems. Retention is unknown until actually observed or measured. Plan a focused change from evidence. |
| Too few observations or windows differ | Continue the same experiment another week; do not declare a winning cover or causal improvement. |

A later cover test needs comparable exposures on the same placement; sequential organic weeks are confounded by audience, algorithm and time. Do not claim statistical significance from 50 visits or use page visits as impressions.
